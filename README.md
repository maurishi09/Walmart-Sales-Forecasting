# Walmart Retail Sales & Demand Forecasting

Exploratory data analysis and demand forecasting on multi-store retail sales data, examining what actually drives weekly sales performance.

## What this project does

Analyzes weekly sales across 45 Walmart stores to identify trends, seasonality, and the impact of external factors — CPI, unemployment, fuel prices, and temperature — on store performance, then builds forecasting models to support inventory and demand planning.

## Stack

Python · Pandas · NumPy · Matplotlib · Statistical Analysis · Time Series Forecasting
